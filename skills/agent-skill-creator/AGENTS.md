# Agent Skill Creator

Use `SKILL.md` for the full Foxwarm-adapted entry point. This companion file exists for tools that discover `AGENTS.md`.

Purpose: create reusable agent skills from workflow descriptions, existing docs, code, transcripts, files, or rough process notes.

Important Foxwarm conventions:

- `SKILL.md` is the automatic entry point.
- Companion docs live in `references/`, scripts, assets, or other explicitly linked files.
- Do not use `memory/*.md` as skill companion docs; Foxwarm does not auto-load them.
- Keep generated skills portable, validated, and free of secrets or private one-off history.

When using this skill, follow the phases in `SKILL.md` and read reference docs only as needed.
