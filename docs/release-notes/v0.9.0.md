Foxwarm is a self-hosted runtime for AI agents: persistent conversations, Agent memory, tool calling and a WebUI, with optional messaging Channels and execution Nodes.

This is the first packaged release. Installing it compiles nothing and needs neither Node.js nor the .NET SDK.

## Install

| Platform | Command |
| --- | --- |
| Linux x64 or x64 WSL | `curl -fsSL https://foxwarm.net/install-foxwarm.sh \| bash` |
| Windows x64, in PowerShell | `irm https://foxwarm.net/install-foxwarm.ps1 \| iex` |
| Docker | `docker run -d --name foxwarm --init -p 3001:3001 -v "$PWD/foxwarm-data:/data" ghcr.io/550w-host/foxwarm:0.9.0` |

The installers download the right package from this release, start Foxwarm and print the WebUI sign-in link. Afterwards, `foxwarm/foxwarmctl` (`foxwarmctl.cmd` on Windows) starts, stops, updates and reports status. See [Install Foxwarm](https://foxwarm.net/docs/installing/) for options and requirements, then [set up your first model](https://foxwarm.net/docs/model-setup/).

## Downloads

| File | Contents |
| --- | --- |
| `foxwarm-linux-x64.tar.gz` | Linux server; uses the installed ASP.NET Core 10 runtime |
| `foxwarm-linux-x64-self-contained.tar.gz` | Linux server with the .NET runtime included |
| `foxwarm-win-x64.zip` | Windows server; uses the installed ASP.NET Core 10 runtime |
| `foxwarm-win-x64-self-contained.zip` | Windows server with the .NET runtime included |
| `foxwarm-desktop-win-x64.zip` | Windows desktop app with the .NET runtime included; extract and open `Foxwarm.Desktop.exe` |
| `SHA256SUMS` | SHA-256 checksums of the files above |

The installers pick the smaller package when ASP.NET Core 10 is installed and the self-contained one otherwise. The container image `ghcr.io/550w-host/foxwarm` is tagged `0.9.0`, `0.9` and `latest`.

## Requirements

- Linux: x64 with glibc 2.34 or later (for example Ubuntu 22.04, Debian 12, RHEL 9), ICU and OpenSSL libraries, and tmux for background start. Semantic history search needs glibc 2.39.
- Windows: x64. The desktop app also needs the Microsoft Edge WebView2 Runtime, which Windows 10 and 11 normally include.
- Optional: Node.js on `PATH` for chart, image and React artifacts; Chromium or Chrome for the browser tool.

## Existing installations

- A source checkout can keep running from source; `npm run restart` continues to work. To move it to a package, stop it and install into a new directory with `--data-dir` (`-DataDir` on Windows) pointing at its existing data directory. The new release checks that data before it starts.
- TypeScript installations should follow the [migration guide](https://foxwarm.net/docs/typescript-migration/).
- Back up the whole data directory first; see [data, updates, and backups](https://foxwarm.net/docs/data-upgrades-backups/).

## Known limitations

- The Foxwarm server does not run on macOS. A Mac can still join as a Node.
- The Windows executables are not code-signed, so SmartScreen may warn on first launch.
- The desktop app has no installer or automatic updater; replace the extracted folder to update.
- The Code workbench editor assets and HEIC/HEIF decoders are not included and need a separate setup.
