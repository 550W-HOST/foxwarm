# Foxwarm 0.9.7

## Upgrade notes

- **Windows desktop app.** To move from the extracted ZIP to the new installer, exit Foxwarm from the tray, run `foxwarm-desktop-win-x64-setup.exe` and then delete the extracted folder. The installed app uses the same data, so your Sessions, models and settings carry over. To keep using the ZIP, replace the extracted folder as before.

## Highlights

### Windows desktop installer

- The Windows desktop app now has an installer, `foxwarm-desktop-win-x64-setup.exe`. It installs Foxwarm for your Windows account without administrator rights, adds it to the Start menu and to **Settings → Apps**, and can start Foxwarm in the tray when you sign in.
- To update, run the setup of a newer release. Updating and uninstalling exit a running Foxwarm normally first. Uninstalling keeps your data in `%LOCALAPPDATA%\Foxwarm\Desktop`.
- Setup tells you when the WebView2 Runtime is missing and links to Microsoft's download page.
- `foxwarm-desktop-win-x64.zip` remains available as the portable app. It shares its data with an installed app, and only one of them runs at a time.
- Opening the Windows desktop app while it is already running now shows its window instead of a message.
