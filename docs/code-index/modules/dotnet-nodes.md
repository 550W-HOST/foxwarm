# Module: External Nodes

Persistent administrator-approved trust, credential-authenticated WebSocket connections, compatible capability discovery, Session placement and ordinary external tools.

## Boundaries

This module connects existing CLI/browser/Android Node protocol clients to the .NET host. It does not create environments, grant OS isolation, or connect the full persistent exec/transfer/service lifecycle. [Remote Node integration](../threads/remote-node-compatibility.md#net-external-node-integration) owns the canonical connected contract and remaining phase boundaries.

## Units

- [External Node trust and ordinary tools](../units/external-nodes.md)
- [Unified tools and Session tool execution](../units/tools-registry.md)
- [Tool authorization and isolation compatibility](../units/tool-authorization.md)

## Tests and callers

The external Node unit maps the persistent registry/save-lane tests and real host/official-client qualification. The ordinary Node path uses the existing Session owner and tool authorization; Main-owned observation and history remain available offline.
