## Where to start

1. [Install Foxwarm](/docs/installing/) and keep the program checkout separate from its data directory.
2. [Set up your first model](/docs/model-setup/) in the WebUI first-run screen.
3. Read [Agents, Sessions, and memory](/docs/agents-sessions-memory/) to see where identity, conversation history, and curated knowledge live.
4. Learn how Foxwarm uses [Tools, Skills, and MCP](/docs/tools-skills-mcp/).
5. Add [Nodes](/docs/nodes/) or [Channels](/docs/channels/) when your workflow needs them.
6. Read [Data, upgrades, and backups](/docs/data-upgrades-backups/) before moving an important instance.

For implementation details, start with the repository [Code Index](https://github.com/550W-HOST/foxwarm/tree/main/docs/code-index). The source code and tests define current behavior.
