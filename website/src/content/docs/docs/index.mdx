Foxwarm runs on your machine or server. This site provides the installer and the documentation for setting up and using your own instance.

## Start here

1. [Install Foxwarm](/docs/installing/) on Linux, macOS, WSL, or Windows.
2. [Set up your first model](/docs/model-setup/) in the WebUI.
3. Read [Agents, Sessions, and memory](/docs/agents-sessions-memory/) to see where identity, conversation history, and long-lived knowledge live.

The installer keeps the program checkout separate from its data directory. Your WebUI, API, Agents, model credentials, and runtime data stay on the machine where you run Foxwarm.

## Learn the main parts

- [Tools, Skills, and MCP](/docs/tools-skills-mcp/) explains built-in actions, reusable instructions, and external tool servers.
- [Connect an external MCP client](/docs/mcp-inbound/) shows how to use Foxwarm's authenticated inbound MCP endpoint.
- [Nodes](/docs/nodes/) covers optional execution environments for another machine, a dedicated environment, or supported browser tools.
- [Channels](/docs/channels/) shows how to connect Sessions to supported messaging platforms.
- [Data, upgrades, and backups](/docs/data-upgrades-backups/) describes the data directory and how to update an important instance safely.
- [FAQ](/docs/faq/) answers common installation and configuration questions.

For implementation details, start with the repository [Code Index](https://github.com/550W-HOST/foxwarm/tree/main/docs/code-index). The source code and tests define current behavior.
