Foxwarm is a self-hosted workspace for AI agents that work on long tasks. You run one Foxwarm server. It holds your agents, their conversations and memory, and the model and tool configuration. Agents read code, run commands, hand work to other sessions, and report back in the browser or in a chat app.

## The parts in one minute

- An **Agent** is a long-lived identity with its own memory and rules: for example `main`, `reviewer` or `support`.
- A **Session** is one conversation of an Agent. An Agent can have many Sessions, and a Session can start child Sessions for parts of a task.
- A **Node** is a machine or environment where tools run. The Foxwarm server itself is the `master` Node; you can add servers, laptops, containers and browser tabs.
- A **Channel** connects a chat app such as Telegram, Matrix, QQ, WeChat or WeCom to a Session.

The agent loop, models and credentials stay on the server. Nodes only run the commands they are given. [How Foxwarm works](/docs/how-it-works/) explains this split in more detail.
