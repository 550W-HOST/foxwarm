Foxwarm runs on your machine or server. The project website is documentation and download hosting only; it is not a hosted Foxwarm chat or API service.

<CardGrid>
  <Card title="Install and open WebUI" icon="rocket">

  </Card>
  <Card title="Connect your model" icon="setting">
    First-run Setup writes your model provider, endpoint, model ID, and API key when one is required.
  </Card>
  <Card title="Keep work organized" icon="seti:folder">

  </Card>

## Recommended reading order

1. [Install Foxwarm](/docs/installing/) and keep the program checkout separate from its data directory.
2. [Set up your first model](/docs/model-setup/) in the WebUI first-run screen.
3. Learn how [Agents, Sessions, and memory](/docs/agents-sessions-memory/) divide identity, conversation history, and curated knowledge.
4. Explore [Tools, Skills, and MCP](/docs/tools-skills-mcp/).
5. Add [Nodes](/docs/nodes/) or [Channels](/docs/channels/) only if your workflow needs them.
6. Read [Data, upgrades, and backups](/docs/data-upgrades-backups/) before moving an important instance.

For implementation details and contributor navigation, see the repository [Code Index](https://github.com/550W-HOST/foxwarm/tree/main/docs/code-index). Source code and tests remain authoritative.
