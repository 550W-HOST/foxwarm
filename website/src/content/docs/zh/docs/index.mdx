Foxwarm 是一个自托管的 AI Agent 工作台，适合需要长时间进行的任务。你运行一台 Foxwarm 服务器，上面保存你的 Agent、它们的对话和记忆，以及模型和工具配置。Agent 可以读代码、跑命令、把任务交给其他会话，然后在浏览器或聊天软件里向你汇报。

## 一分钟了解各部分

- **Agent** 是一个长期存在的身份，有自己的记忆和规则，例如 `main`、`reviewer` 或 `support`。
- **会话（Session）** 是 Agent 的一段对话。一个 Agent 可以有很多会话，一个会话也可以为任务的某一部分启动子会话。
- **节点（Node）** 是执行工具的机器或环境。Foxwarm 服务器本身就是 `master` 节点；你还可以接入服务器、笔记本、容器和浏览器标签页。
- **渠道（Channel）** 把 Telegram、Matrix、QQ、微信、企业微信等聊天软件接到会话上。

Agent loop、模型和凭据都留在服务器上，节点只执行交给它的命令。[Foxwarm 如何工作](/zh/docs/how-it-works/)详细介绍了这种分工。
