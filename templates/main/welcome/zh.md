你好，我是 Foxwarm 🦊。我在安装 Foxwarm 的那台电脑上工作：可以编辑文件、运行命令、编写和调试代码、查找资料，也能持续跟进较长的项目。

**先了解几个概念**

- 你现在在 `main`，它是默认 Agent `main` 的默认 Session。
- 一个 **Session** 是一段独立的对话，对应一件事情。点 Session 列表上方的 **+** 就能开始新的 Session。
- **Agent** 为它的各个 Session 保存长期记忆和文件。刚开始一个就够了。
- 命令和文件操作都在安装 Foxwarm 的那台电脑上执行，不一定是你眼前的这台设备。

**需要更多功能时，直接让我**

- 为需要长期单独进行的工作创建一个专门的 Agent，它有自己的记忆；
- 在指定时间运行任务，或按计划定期运行；
- 把另一台电脑连接为 Node，让我也能在那里工作；
- 接入 MCP 服务器，为我添加更多工具。
